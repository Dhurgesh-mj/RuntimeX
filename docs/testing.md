# Testing — RuntimeX Runtime Core (Person 1)

All commands run from the repository root. No results in this file were
fabricated: each test listed below was executed on the documented
environment (Ubuntu 24.04, x86_64, glibc 2.39, gcc 13.3, `make`/GNU make,
python3 ≥ 3.11 with `jsonschema` optional-but-present).

## Quick start

```sh
make all    # library + targets + tests
make test   # runtime tests + JSONL/schema validation
make check  # test + baseline comparison + logging-failure + vulnerable run
make bench  # overhead measurement (informational)
make clean  # remove build/ and logs/
```

## Sample sessions (actual commands)

```sh
# Instrumented run with a chosen log file

  RUNTIMEX_LOG=/tmp/opencode/demo.jsonl ./build/safe_demo

# Validate every log generated by make test
python3 tests/test_event_schema.py logs/*.jsonl build/*.jsonl
```

## Environment-dependent limitations

- `make check-logging-failures`'s read-only-file case assumes the user is
  not root (root ignores mode bits and could write the log).
- `/dev/full` must exist (standard on Linux).
- Timing in `make bench` uses `/usr/bin/time` (GNU coreutils).
- Python full-schema validation silently degrades to built-in checks when
  `jsonschema` is not installed; both modes exited 0 here.
